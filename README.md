# Python Calculator 🧮

A simple command-line calculator built with Python.

## Features

- Addition, subtraction, multiplication, and division
- Input validation
- Division by zero protection
- Invalid operator handling
- Repeat calculations

## Concepts Used

- Variables
- User input
- If/elif/else statements
- While loops
- Functions
- Try/except
- Break and continue
- Float numbers
